# Big-Data-Analystics-Dashboard
# Dashboard Bisnis: Deteksi Dini Penyakit Padi

Repositori ini berisi kode sumber untuk halaman statis *Dashboard* KPI (Key Performance Indicator) yang mendukung proses pemantauan, diagnosis, mitigasi, dan hasil panen untuk Food Estate Kalimantan Tengah.

## Fitur Utama
- **Risiko Iklim:** Analisis hari kelembapan tinggi dan curah hujan tahunan.
- **Hasil Panen:** Data produktivitas wilayah per tahun.
- **Simulasi Bisnis:** Kalkulator interaktif kerugian yang dapat dicegah melalui deteksi dini.
- **Katalog KPI:** Metrik proses bisnis berdasarkan status ketersediaan data.

## Sumber Data
- Data cuaca NASA POWER 2023–2025.
- Data panen Badan Pusat Statistik (BPS).
- Hasil evaluasi model *Convolutional Neural Network* (CNN).
